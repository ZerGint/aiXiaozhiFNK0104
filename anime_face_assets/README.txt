ANIME FACE — 240×240, текущий комплект для визуальной проверки

Используйте только base_240.png из этого архива: из неё убраны глаза,
рот и брови; выполнена последняя коррекция волос.

Папки:
 eyes/ — 2 белка, 2 радужки, 10 состояний век.
 mouth/ — 5 состояний рта.
 brows/ — 2 брови.
 preview/ — итоговый GIF и нейтральная композиция.
 manifest.json — размеры и точные координаты всех слоёв.

Порядок: BASE → белки → радужки → веки → рот → брови.
Left/right означают стороны экрана.
Радужки при смещении ОБЯЗАТЕЛЬНО обрезать по неподвижной alpha-маске
соответствующего белка. Проверенное смещение X: −4…+4 px, Y: 0.
При моргании положение радужек не сбрасывать.
Веки: 0 открыто, 1 ~25%, 2 ~50%, 3 ~85%, 4 закрыто.
В каждом новом кадре заново собирать слои от BASE, чтобы не было следов.
Брови: небольшое вертикальное движение −1…+1 px.

PNG — RGBA. GIF только для предпросмотра, с ограниченной палитрой.
Программно восстановленные волосы/кожа и новые открытые формы рта
требуют окончательной визуальной проверки. Аудиосинхронизация не включена.

Дополнение: эмоции

 Оба: 34×22, позиция (103,155), заменяют текущий рот.
