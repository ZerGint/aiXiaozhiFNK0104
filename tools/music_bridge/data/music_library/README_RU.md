# Пользовательская музыкальная библиотека

Сюда можно копировать любые MP3-файлы, которые должны быть доступны для
поиска с устройства FNK. Мост просматривает эту папку автоматически, поэтому
перезапуск приложения после добавления файла обычно не требуется.

Эта папка отличается от `../library`:

- `music_library` — ваша обычная музыка;
- `../library` — архив уже сгенерированных мостом треков.

При запросе из FNK пользовательский трек скачивается на SD-карту устройства в
`/sdcard/music` и появляется в обычном плеере. Сгенерированный трек по-прежнему
скачивается в `/sdcard/generated_music` и отображается во вкладке GEN.

Для поиска используются название файла и MP3-теги (название, исполнитель,
альбом). Поддерживаются MP3-файлы, включая файлы во вложенных папках. Не
переименовывайте и не удаляйте файл во время скачивания.
